# CartePro

## Requirements

Before running the project, make sure you have:

- Docker
- Docker Compose
- OpenSSL

Docker installation:

https://docs.docker.com/engine/install/

## Setup

Make all scripts executable:

```bash
chmod +x *.sh
```

## Run

./setup.sh

You will be asked to configure the .env in cli:

## Verify

https://localhost
